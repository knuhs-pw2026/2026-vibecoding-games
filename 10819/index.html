아빠의 마지막 뇌파가 꺼지기 전 진심을 전하기 위해 울며 손을 꼭 쥐고 있는 딸 하은이가 있었습니다.

평생을 짓눌렀던 죄책감과 후회는 눈부신 은하수가 되어 흩어지고,
두 사람은 가장 따스했던 사랑의 기억 속에서 영원히 함께하게 됩니다.

📑 프로젝트 개요: 너에게 닿는 마지막 문 (The Last Door to You)

장르 : 감성 내러티브 스토리 방탈출 어드벤처 | 타깃 : PC (Steam), 모바일
핵심 콘셉트 : 딸의 무의식 속에 갇힌 아빠가 기억의 퍼즐을 풀며 탈출하는 여정인 줄 알았으나, 사실은 임종을 앞둔 아빠를 위해 딸이 준비한 마지막 사랑의 배웅이었음을 밝혀내는 눈물겨운 휴먼 드라마.

🎮 4대 핵심 게임플레이 메커니즘

1. 기억의 렌즈 (Reminiscence Lens) : 차가운 현재 공간을 렌즈로 비추면 과거 따스했던 당시의 단서와 메시지가 시각적으로 복원되는 시스템.
2. 감정의 오르골 & 피아노 조율 : 추억의 멜로디 조각을 직접 연주하여 잠긴 비밀 공간을 개방하는 사운드 인터랙션.
3. 시간의 폴라로이드 : 과거의 사진을 현상하며 전하지 못한 편지와 날짜를 획득.
4. 진심의 일기장 : 챕터 클리어 시마다 부녀의 시점이 교차 서술되며 깊은 감정적 카타르시스를 선사.

📖 챕터별 구성 요약

- Ch 1. 멈춰버린 시계의 서재 (7세) : 자전거의 약속과 종이 메달 획득.
- Ch 2. 비 내리는 온실과 피아노 (14세) : 사춘기의 다툼과 빗소리 피아노 듀엣 연주.
- Ch 3. 빛바랜 병실의 서재 (20세) : 딸의 독립과 아빠의 숨겨진 투병 일기.
- Ch 4. 은하수가 흐르는 마지막 문 (진실) : 진짜 진실의 반전과 감동의 작별 인사.
