# 🏫 경북대사대부고 축제용 텍스트 탈출 게임 : 《검은 그늘 속에서》

> **웹소설 《괴담에 떨어져도 출근은 해야 하는구나》의 '검은 그늘 속에서' 괴담을 모티브로 한 학교 축제 전용 인터랙티브 웹 탈출 게임입니다.**

---

## 🎮 게임 특징 및 시스템

1. **축제 현장 최적화 (QR 스캔 즉시 실행)**
   - 별도의 앱 설치 없이 브라우저(모바일/PC)에서 바로 실행됩니다.
   - 평균 플레이 타임: **5~8분** (부스 대기열 순환에 최적).

2. **몰입감 넘치는 다크 호러 연출**
   - **CRT 스캔라인 & 글리치 효과**: 낡은 모니터/텍본 감성 연출.
   - **실시간 오염도(Sanity) 비네팅**: 어둠에 침식될수록 화면 주변부가 붉게 물들고 심장 박동 소리가 빨라집니다.
   - **Web Audio 내장 사운드 엔진**: MP3 다운로드 없이 브라우저 자체에서 타자기, 긴장 앰비언스, 심장 소리, 승리 팡파레를 실시간 합성.

3. **원작 기믹 & 사대부고 로컬라이징**
   - **검은 눈물의 학생들**: 책걸상과 일체화되어 가는 공포.
   - **사대부고 야간 행동 수칙서**: 버튼으로 언제든 열어볼 수 있는 생존 지침서 모달.
   - **핵심 아이템**: `소형 손전등`, `2학년 만년필(암시)`, `사대부고 교복(위장)`, `호신 부적`, `안정제`.
   - **정체성 자각**: *"나는 축제를 즐기러 온 사대부고 학생이다!"*를 통한 어둠 정화.

4. **멀티 엔딩 & 축제 상품 수령용 디지털 인증서**
   - 🏆 **진엔딩 (TRUE END)** : 햇살 속의 축제 귀환
   - 👑 **히든엔딩 (SECRET END)** : 사대부고 전설의 탈출왕 (오염도 20% 이하 + 전 단서 수집)
   - 💀 **배드엔딩 3종** : 영원한 자습(책걸상 동화), 복도의 그림자, 잊혀진 이름
   - **황금 디지털 인증서** : 플레이 타임, 남은 오염도, 위조 방지 6자리 랜덤 인증 코드(`KNU-XXXXXX`) 발급.

## 🚀 축제 부스 운영 및 배포 방법

### 1. 로컬에서 바로 실행하기
- `index.html` 파일을 더블 클릭하여 크롬이나 웨일, 사파리 등의 웹 브라우저에서 바로 열 수 있습니다.

### 2. 인터넷 무료 배포 (QR 코드 생성용)
- **GitHub Pages / Netlify / Vercel**에 해당 폴더를 그대로 업로드하면 1분 만에 웹 링크(`https://your-name.github.io/...`)가 생성됩니다.
- 생성된 링크를 [무료 QR코드 생성 사이트](https://www.qrcode-monkey.com/)에 입력하여 QR코드를 다운로드합니다.
- 축제 부스 포스터나 안내 팻말에 QR코드를 인쇄하여 부착하면 관람객들이 스마트폰 카메라로 스캔하여 바로 플레이할 수 있습니다.

### 3. 부스 상품 지급 방식
- 관람객이 탈출에 성공하면 화면에 **[학교 축제 탈출 성공 증명서]**가 뜹니다.
- 스태프는 화면의 **'탈출 랭크'** 및 **'인증 코드'**를 확인한 후 준비된 사은품(간식, 스티커, 음료수 등)을 지급하시면 됩니다.
