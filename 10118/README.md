## 🎯 업데이트 및 주요 개선 사항

### 1. ⚡ 완벽한 조작감 (관성 제거)
- 가속도와 미끄러짐을 완전히 제거하고, 키를 누르면 즉각 최고 속도(`5.0px/frame`)로 이동하고 키를 떼면 즉시 멈추도록 변경하였습니다.
- 좁은 발판이나 가시 바로 앞에서도 정밀하게 위치를 잡고 점프할 수 있습니다.

### 2. ☠️ 시체 개수 제한 (Max Corpse Limit)
- 각 스테이지마다 생성 가능한 최대 시체 개수(예: 2개, 3개 등)를 제한하여 퍼즐의 전략성과 밸런스를 강화했습니다.
- 상단 HUD에 `CORPSE LIMIT: 1 / 3` 형태로 실시간 표시되며, 한도를 초과하여 사망할 경우 화면 상단에 경고 토스트가 뜨며 스테이지가 자동 리셋됩니다.

### 3. 🪜 시체 2단/3단 탑 적재 (Stacking) 메커니즘
- 같은 위치의 지상 가시와 공중 가시에 연속으로 몸을 던져 **시체를 2층, 3층 탑 형태로 차곡차곡 쌓아** 일반 점프로는 닿을 수 없는 초고층 절벽을 돌파할 수 있습니다.
- 시체 위에 서 있을 때는 안전하지만, 시체 위에서 점프하여 가시에 다시 닿으면 추가 시체가 생성됩니다.

## 🗺️ 10개 전 스테이지 클리어 검증 가이드

| 스테이지 | 이름 | 시체 한도 | 핵심 기믹 및 클리어 해법 |
| :--- | :--- | :---: | :--- |
| **Stage 1** | **첫 번째 희생** | 2개 | 2칸 높이 벽 앞 가시에 1번 사망 ➜ 생성된 시체를 밟고 2칸 벽을 넘어 골인 |
| **Stage 2** | **시체의 다리** | 3개 | 3칸 가시 웅덩이에 차례대로 몸을 던져 2~3개의 시체로 안전한 다리를 놓아 건너기 |
| **Stage 3** | **2층 테라스** | 2개 | 4칸 높이의 2층 테라스. 중간 지상 가시에서 1번 사망 후 시체 위에서 점프하여 2층 안착 |
| **Stage 4** | **희생의 무게** | 2개 | 레이저 문 앞 스위치 가시에 뛰어들어 사망 ➜ 시체가 스위치를 영구 가압하여 문 개방 ➜ 통과 |
| **Stage 5** | **시체 2단 탑** | 3개 | 지상 가시(1단) + 공중 가시(2단)에 차례로 죽어 2단 시체 탑을 쌓고, 5칸 높이의 고층 테라스 돌파 |
| **Stage 6** | **점프 패드 도약** | 2개 | 점프 패드로 튕겨올라 공중 가시에서 사망하여 공중 시체 발판 생성 ➜ 재도약 후 공중 시체 밟고 골인 |
| **Stage 7** | **이중 레이저 문** | 3개 | 1번 스위치 가시(문1 개방) + 2번 스위치 가시(문2 개방)에 각각 시체를 남겨 2중 보안문 돌파 |
| **Stage 8** | **4연속 가시 계곡** | 4개 | 넓은 4칸 가시 계곡에 징검다리 형태로 시체 3개를 투하하여 연속 점프로 계곡 횡단 |
| **Stage 9** | **천장 가시 드롭** | 3개 | 2층 천장 가시에 머리를 박고 사망하면 시체가 아래 1층 깊은 가시밭으로 수직 낙하 ➜ 안전해진 1층으로 골인 |
| **Stage 10** | **궁극의 탈출** | 3개 | 스위치 사망(문 개방) ➜ 점프패드 ➜ 공중 가시 사망(공중 발판) ➜ 점프패드 2단 도약 ➜ 최종 천공 포털 클리어! |

## 🕹️ 조작 키 안내
- **이동**: `←`, `→` 또는 `A`, `D` (관성 없이 즉시 정지)
- **점프**: `↑`, `W`, `Space`
- **스테이지 리셋**: `R`
- **사운드 On/Off**: `M`
